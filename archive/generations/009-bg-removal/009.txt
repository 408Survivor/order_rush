# 批次 009 — 素材去底（白底→透明）

日期：2026-08-01
任务：全部角色/物品素材为白底（RGB 无 alpha），影响游戏观感 → 去除白底

## 平台与工具
- Python 3.9.6 + Pillow 10.4.0 + OpenCV 4.13.0（cv2 系统已预装）
- pip 与 ~/Library/Python 被 macOS TCC 拦截 → 依赖用 `pip3 install --target /tmp/pylibs` 绕过

## 方法（两个脚本，保留于本批次目录）
1. `remove_white_bg.py` — 连通域泛洪去底
   - 原理：从图片四边 BFS 泛洪，仅删除"与边缘连通的近白像素"
   - 角色/物品内部白色（厨师服）与边缘不连通 → 保留
   - 参数：默认阈值 245；`--feather N` 边界羽化（处理背景渐变带噪点）
2. `grabcut_bg.py` — GrabCut 交互式分割（OpenCV）
   - 原理：颜色模型 + 轮廓梯度区分前景/背景
   - 用于"白色主体+白色背景"（亮度法失效的场景）

## 经验记录
- **白主体 + 白背景是亮度法的死穴**：dish 图白盘与背景渐变亮度连续且中央连通，
  阈值 225 误删白盘、245 删不净背景、双阈值保护块会把中央背景一起保护（31% 图面）
- 连通域"盘沿分隔带"决定成败：盘沿 225-245 的分隔在 245 阈值下隔开背景与盘子（盘子保留），
  225 阈值下被打通（盘子被删）——任何单一阈值都不可兼得
- GrabCut 初始化矩形必须**盖住整个主体**：rect(0.15,0.2,0.85,0.8) 时盘子右半被切，
  扩大到 rect(0.02,0.05,0.98,0.95) 后完整（用户确认"完美"）
- 已验证用户确认：player 去底（阈值245）✅、dish GrabCut v2 ✅
- 后续素材（#1 微波炉重生成等）建议直接让 AI 生成透明背景，或按本批次流程处理

# 🍜 爆单时刻 (Order Rush)

> 一款 2D 俯视角预制菜小餐馆经营模拟游戏，融合《飞机大厨》的高频操作爽感与《杯杯倒满》的 PC 键盘经营深度。支持"堂食+外卖"双线程，核心乐趣是时间管理 + 订单调度 + 空间移动。

---

## 📋 项目信息

| 项目 | 内容 |
|------|------|
| **引擎** | Godot 4.4.x (GDScript) |
| **平台** | PC (itch.io → Steam) |

| **当前阶段** | 🔄 Phase 0: 美术风格锁定（进行中） |
| **总体进度** | 30%（2/6 核心素材已生成） |

**📌 文件存放铁律**:
- `.tscn` 只能出现在 `scenes/` 及其子目录
- `.gd` 只能出现在 `scripts/` 及其子目录
- `.png` / `.jpg` 只能出现在 `assets/art/` 中
- `.ogg` / `.wav` / `.mp3` 只能出现在 `assets/audio/` 中
- **根目录禁止堆放任何资源或脚本**

## 🎮 游戏核心玩法（一句话）

> **开店前备料 → 营业中手忙脚乱 → 打烊后算账 → 用利润升级设备 → 进入下一天**

| 系统 | 核心乐趣 |
|------|----------|
| **预制菜出餐** | 三级体系：L1 即热（6秒）→ L2 即烹（14秒）→ L3 现做（25秒） |
| **外卖调度** | 订单到达 ≠ 骑手到达，用时间裕度（红黄绿蓝）决定优先级 |
| **经营循环** | 单局 7-10 分钟，收入 - 成本 = 净利润，升级设备 |
| **卡牌构筑** | 打烊后口碑抽卡，走量流/品质流/外卖专精/堂食专精 |

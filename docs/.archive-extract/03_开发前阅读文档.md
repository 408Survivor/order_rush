## 3. 技术细节

- **引擎/语言**：Godot 4.x + GDScript（文档既定）
- **AI 生成工具**：即梦 5.0 Lite（已锁定风格）
- **生成参数（本会话统一使用）**：1024×1024 / 1:1 / 勾选透明背景 / 风格强度 75%（文档建议范围 70–85%）/ 一次 4 张选最佳；实际产出图为 2048×2048 PNG
- **俯视角提示词演进**：
  - v1 `top-down perspective` → 即梦输出正面图（失败，Session 1 教训）
  - v2 `Overhead view, bird eye view from directly above, looking straight down from ceiling` → 002/003 批次成功（英文长句版）
  - v3 中文精简版 `俯视正上方，从天花板正下方看` → 004–007 使用；注意 v3 对"微波炉"这类训练数据默认为正面图的物体仍会偏 3/4 视角
- **风格基准**：扁平插画 + Q版比例（大头小身）+ 暖色高饱和 + 粗线条描边 + 左上光源
- **Godot 导入设置（文档既定，待执行）**：Filter: Nearest（Tile 必须）；Size Limit：角色/设备 512、小物品 256；地板走 TileMapLayer + TileSet atlas，Tile Size 64×64，Repeat: Enabled
- **中文标签方案**：素材不生成文字，后期用 Godot Label 节点叠加
- **订单气泡**用 NinePatchRect、**耐心条**用 TextureProgressBar（文档既定）
- **即梦平台规则实测**：① 无负面提示词输入框；② 大量 `no xxx` 否定句会被判违规；③ 输出图右下角带即梦水印；④ 勾选"透明背景"不保证生效，需提示词文本配合

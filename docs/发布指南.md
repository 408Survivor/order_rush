# 爆单时刻 — 发布指南（itch.io）

> P9 Polish 构建流程（issue #46）。`export_presets.cfg` 已在本地生成（gitignore 不提交）。

## 前置条件

1. **Godot 4.6.3 Web 导出模板**（一次性）：
   - 打开 Godot → 菜单 `编辑器` → `管理导出模板` → 下载并安装 `4.6.3` 模板（需联网）
2. **butler**（itch.io 上传工具）：`brew install butler` 或官网下载；首次运行 `butler login`

## 导出 Web 版本

```bash
# 项目根目录
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "Web" build/web/index.html
```

> 注意：macOS 26 TCC 下 headless 可能崩溃 → 改用 GUI：打开项目 → `项目` → `导出` → 选 `Web` 预设 → `导出项目` 到 `build/web/`。
> 若 GUI 导出报错，可用 `open -a Godot --args --path .` 启动后手动导出（Readme 启动方式）。

## 上传 itch.io

```bash
butler push build/web 你的用户名/order-rush:html5
```

- 首次会创建页面；`html5` 为 Web 渠道
- 更新版本：重复 push 即可（butler 自动差分）
